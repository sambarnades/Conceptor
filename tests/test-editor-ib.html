Tests e2e — Editeur InteractiveBook

Schema, showWhen, normalisation, denormalisation, exercices, tables, couleurs, LaTeX

Ce que ces tests verifient

Tests end-to-end pour l'editeur CoursePresentation :

  1. Schema — Structure correcte, sections, champs, types.
  2. showWhen — Visibilite conditionnelle par type de slide (title, content, quiz, etc.).
  3. exerciseLibrary — 9 types d'exercices, dynamicObject, schemas CP_EXERCISE_SCHEMAS.
  4. Detection — detectContentType identifie CoursePresentation dans les 3 exemples.
  5. Normalisation — exercise.library → _exerciseLibrary, titres preserves.
  6. Structures — Chaque type de slide a les bons champs (tables, exercices, etc.).
  7. Aller-retour — normalize → denormalize preserve toutes les donnees.
  8. Modifications — Ajout de slides, changement de type, modification d'exercices.
  9. Couleurs — Champs type: 'color', assignation et preservation.
  10. Tables — Headers, rows, styles (6 styles dont DSFR).
  11. LaTeX — Preservation des delimiteurs mathematiques.
  12. Robustesse — Slides vides, exercice manquant, library inconnue.
