Tests Editeur - Mutations (add / remove / duplicate / move)

Verifie que les mutations sur la nav primaire ne corrompent pas les items voisins ni le suivi de selection.

Ce que ces tests verifient

Bug historique : navigateTo() rappelait collectCurrentViewData() apres une mutation structurelle (splice). Le DOM contenait encore des <input data-path="cards.N.*"> obsoletes, donc la collecte ecrasait l'item voisin avec les valeurs de l'item supprime / deplace.

  • Suppression : l'item suivant doit conserver son contenu original.
  • Ajout : insertion en fin, navigation sur le nouvel item, voisins intacts.
  • Duplication : copie de l'item courant, voisins intacts, navigation sur la copie.
  • Deplacement : suivi par identite de l'item affiche, meme s'il n'est pas le deplace.
  • Sequence combinee : add + remove + move sans corruption.
