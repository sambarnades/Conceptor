Tests images H5P Caramel

Traitement → Registre → buildMediaStructure → Processeurs H5P → Packaging ZIP → Export document → Cycle complet

Comment ca marche ?

Objectif : Tester l'integration complete des images dans les activites H5P : traitement (PNG, WebP → JPEG), registre, injection dans les processeurs, packaging ZIP, export document.

  1. Traitement images — Charge logo_caramel.png et logo_caramel_2.webp, les convertit en JPEG via processImage(). Teste aussi le rejet de fichiers trop gros ou de format invalide.
  2. Registre — Cycle de vie complet : register, get, unregister, re-register, getAllImages, clearAllImages.
  3. buildMediaStructure — Structure media H5P avec et sans image, avec et sans alt text.
  4. Processeurs H5P — Injection d'images dans 9 activites (Flashcards, DialogCards, DragAndDrop + 6 media) et verification des structures produites.
  5. Packaging ZIP — Creation de fichiers .h5p avec images : verification de l'image binaire dans le ZIP, reference dans content.json, dependance H5P.Image.
  6. Export document — formatContentForDocument() avec images media : verification des sections type: 'image' generees.
  7. Cycle complet — Ajout image → retrait → re-ajout : verification ZIP a chaque etape.
