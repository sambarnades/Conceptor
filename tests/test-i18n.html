Tests i18n Caramel

Integrite fichiers → Coherence cles → Qualite valeurs → Fonction t() → Changement langue → Couverture definitions → Performance

Comment ca marche ?

Objectif : Valider le systeme d'internationalisation apres la migration JS → JSON. Verifie l'integrite des 11 fichiers de langue, la coherence des cles, la qualite des valeurs (prompts, HTML), et les performances.

  1. Integrite fichiers — Chaque fichier js/locales/*.json se charge via fetch() et parse correctement.
  2. Coherence cles — Les 11 fichiers ont exactement les memes cles que fr.json, dans le meme ordre.
  3. Qualite valeurs — Pas de valeurs vides, pas de whitespace parasite dans le HTML, retours a la ligne preserves dans les prompts.
  4. Fonction t() — La fonction de traduction retourne la bonne valeur ou la cle brute si inconnue.
  5. Changement langue — loadTranslations() charge successivement les 11 langues sans erreur.
  6. Couverture definitions — Chaque module d'activite a ses cles de traduction (nom, description, onglets, erreurs).
  7. Performance — Temps de chargement, changement de langue, et translatePage() sous les seuils.
