Tests coherence definitions Caramel

Champs requis → Processeurs H5P → Processeurs Moodle → Prompts → Exemples → Unicite IDs → customOrder → Traductions → Images

Comment ca marche ?

Objectif : Verifier que toutes les activites dans definitions.js sont correctement cablees avec leurs processeurs, prompts, exemples, traductions et images. Detecte les oublis lors de l'ajout d'un nouveau type d'activite.

  1. Champs requis — Chaque module H5P/Moodle a tous ses champs obligatoires.
  2. Processeurs H5P — Chaque module H5P a un processeur dans h5p/processors/.
  3. Processeurs Moodle — Chaque module Moodle a un processeur dans moodle/processors/.
  4. Prompts — Chaque module a un fichier .md dans assets/data/prompts/.
  5. Exemples — Chaque module a au moins un fichier JSON dans assets/data/examples/.
  6. Unicite IDs — Pas de doublons dans les IDs HTML (promptId, createBtnId, etc.).
  7. customOrder — Pas de doublons, chaque module visible est present.
  8. Traductions — Chaque module a ses cles name et description dans fr.json.
  9. Images — Chaque image referencee existe sur le disque.
