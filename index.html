Comment utiliser cet outil ?

  1. Choisissez le mode de création :
    • Mode Rapide : Idéal pour démarrer vite. Indiquez votre rôle (ex: Enseignant) et le sujet à traiter.
    • Mode Guidé : Pour plus de précision. Renseignez la discipline, le thème, le niveau et le nombre d'éléments souhaités.
  2. Générez les prompts en cliquant sur le bouton dédié.
  3. Sélectionnez une activité parmi les tuiles H5P ou les modules Moodle/Éléa.
  4. Utilisez le prompt : Copiez le prompt généré pour le coller dans une IA (ChatGPT, Le Chat...).
  5. Créez et téléchargez : Collez le texte de l'IA pour générer et télécharger votre module.
  6. Finalisez : Importez le fichier .h5p ou .mbz dans votre plateforme (Éléa, Moodle...).
