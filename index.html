Caramel

Création Assistée de Ressources et d'Activités Moodle et Eléa

Comment utiliser cet outil ?

  1. Renseignez le contexte : Indiquez la discipline, le thème, le niveau et le nombre d'éléments souhaités.
  2. Générez les prompts : Cliquez sur le bouton "Générer les prompts".
  3. Choisissez une activité : Cliquez sur une des tuiles H5P ou un module Éléa/Moodle.
  4. Utilisez le prompt : Copiez le prompt généré et collez-le dans votre IA favorite (ChatGPT, Le Chat, Duck.Ai, etc.).
  5. Créez votre module : Collez le résultat de l'IA dans la zone "Créer le fichier H5P complet" et téléchargez votre module.
