# Prompts des 27 H5P — 12 septembre 2026

Les 27 familles de prompts ont été enrichies dans chacune des 12 locales, vérification par comparaison avec le commit `173ec2c2` précédant ce lot d’audit. Cela porte sur les consignes réellement assemblées pour l’IA, pas seulement sur les modèles Markdown.

## Où se trouve le texte envoyé

Dans Caramel, `js/services/prompt-generator.js:buildActivityPrompt` assemble le contexte commun, les règles propres à l’activité, les règles pédagogiques, les sources, la structure JSON et l’exemple depuis `js/locales/<lang>.json`. Les clés d’activité se terminent notamment par `_regles_specifiques`, `_structure_json` et `_exemple_rendu`. Le résultat sert au prompt initial, avec les paramètres de l’enseignant.

`assets/data/prompts/` conserve les modèles de référence. Ils ne sont pas lus par ce chemin d’exécution. Il faut reporter une évolution de ces modèles dans les clés de langue pour qu’elle guide effectivement l’IA. La vérification présente ne certifie pas une identité textuelle intégrale entre chaque modèle Markdown et sa locale.

Sucrerie n’embarque pas ce générateur ni ces familles de clés : ses éditeurs partagés sont synchronisés, mais il n’y a pas de second exemplaire de ces prompts à recopier dans `i18n/`. Ce constat et les décisions sont reportés dans les deux dépôts.

## Réglages confirmés avec l’utilisateur

- **Livre H5P généré : au moins trois chapitres**, dans le modèle et les douze locales. Une demande numérique de un ou deux chapitres en mode guidé est portée à trois dans le prompt. Les fichiers H5P importés conservent leur contrat natif d’édition.
- Vidéo : la structure JSON admet explicitement `pause:false` si demandé et l’omission du résumé sur demande, en accord avec les règles ajoutées précédemment.
- Graphique : en mode rapide, le marqueur du nombre de données est résolu à cinq lorsqu’aucune série n’est fournie ; une série fournie reste prioritaire.
- Cartes de dialogue en anglais : l’alternative rapide/guidée emploie désormais le séparateur réellement interprété par le générateur.

## Vérification

`node tests/run_h5p_prompt_contracts.mjs` assemble réellement **648 prompts : 27 activités × 12 langues × 2 modes**, sans appel IA. Tous contiennent leur structure et leur exemple, sans variable ni alternative laissée brute. Le banc vérifie aussi les demandes de 1, 2, 3 et 4 chapitres dans chaque langue et la pause vidéo facultative. Vérificateur de locales conforme ; le banc vidéo existant `node tests/run_interactive_video_prompt.mjs` passe également.

Ce contrôle ne mesure pas la qualité de centaines de générations IA : les essais distants restent ceux déjà autorisés et archivés. Les options nouvellement documentées restent facultatives selon la demande et les capacités du modèle de génération ; rendre un champ éditable ne signifie pas que l’IA doit le remplir systématiquement.
